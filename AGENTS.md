# `butler`

This is the repo for `butler`, a "server" for Code Server sessions. It packages them up into a nice Tauri app for users to manage their sessions without the hassle of the browser. Necessary? No. Marginally more convenient? Yes.

## Directions

See DESIGN.md for instructions on how the app is supposed to be designed. It's a Tauri app. Include build instructions and how-to-run instructions in the README. Whenever something changes that might affect running or building, document it in the README.

## Best Practices

Remember: KISS. Keep It Simple, Stupid. We're not building a full-on production-grade app. We're building an app that's simple to use and good enough for researchers to use to manage their sessions. Scope-creep, useless tests, excessive hashes and checksums, complex patterns -- it's all bunk. Keep it as simple as possible.

Plan only for the feature ahead of you. Future-compatibility, extra validation for unlikely scenarios, and preparing for details beyond the spec and what's asked of you is pointless and should be eliminated.
